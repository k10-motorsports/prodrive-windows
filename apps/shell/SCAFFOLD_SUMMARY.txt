DECISION NOTES:
===============

1. Auto-updater uses electron-updater (not Squirrel) for future-proofing
2. Two installers: NSIS (primary, no Store needed) + MSIX (Store variant)
3. MSIX auto-updates managed by Microsoft Store, not our app
4. Single-instance lock imperative on Windows for OAuth callback routing
5. Dev mode enables DevTools; prod mode is silent with auto-update checks
6. No hardcoded auth — all handled by web app (NextAuth + Discord)
7. Custom protocol scheme (racecor-prodrive://) reserved for OAuth callbacks
